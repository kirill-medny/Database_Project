### <a id="title1">1. Цель проекта</a>
В рамках проекта нужно получить данные о компаниях и вакансиях с сайта hh.ru, 
спроектировать таблицы в БД PostgreSQL и загрузить полученные данные в созданные таблицы.

Основные шаги проекта
Получить данные о работодателях и их вакансиях с сайта hh.ru. Для этого используйте публичный API hh.ru и библиотеку 
requests.
Выбрать не менее 10 интересных компаний, от которых вы будете получать данные о вакансиях по API.
Спроектировать таблицы в БД PostgreSQL для хранения полученных данных о работодателях и их вакансиях. 
Для работы с БД используйте библиотеку psycopg2.
Реализовать код, который заполняет созданные в БД PostgreSQL таблицы данными о работодателях и их вакансиях.
Создать класс DBManager для работы с данными в БД.

  
### <a id="title2">2. Описание модулей (пакет `src`)</a>

1. Модуль `main.py` содержит код для запуска приложения в целом.

Главный файл, точка входа в программу.
Создает экземпляры классов DBManager и HeadHunterAPI.
Определяет последовательность действий:
Создает базу данных и таблицы, если их нет.
Получает данные о компаниях: либо из API, либо из файла, если он существует. Если из API, то сохраняет в файл.
Сохраняет данные о компаниях и вакансиях в базу данных.
Предоставляет пользовательский интерфейс для выбора операций с данными.
Использует функции из utils.py для работы с файлами.
Использует конфигурацию из config.py.

Переменная `company_ids` содержит список id компаний по которым происходит поиск. при необходимости можно изменить его

2. Модуль `api_client.py` содержит класс HeadHunterAPI, который отвечает за взаимодействие с API hh.ru:
   - `get_company()` - Получает информацию о компании по её ID.
   - `get_vacancies()` - Получает список вакансий компании по её ID.
      в переменную area можно указать id региона для поиска вакансий
      id страны, региона или города можно найти на сайте https://api.hh.ru/areas/
      id России: 113
      id Ставропольского края(по умолчанию): 1481
      id Ставрополя: 84


3. Модуль `utils.py` содержит вспомогательные функции, необходимые для работы функции основной функции:
   - `save_companies_to_file()` - Сохраняет список компаний в файл в формате JSON в директорию data.
   - `load_companies_from_file()` - Загружает список компаний из файла JSON.
   

4. Модуль `db_manager.py` отвечает за управление базой данных PostgreSQL:
   - `create_database()` - Создает базу данных, если она не существует.
   - `create_tables()` - Создает таблицы employers и vacancies с необходимыми полями и связями.
   - `save_companies_to_db()` - Сохраняет данные о компаниях в таблицу employers.
   - `save_vacancies_to_db()` - Сохраняет данные о вакансиях в таблицу vacancies.
   - `get_companies_and_vacancies_count()` - Получает список компаний и количество их вакансий. 
   - `get_all_vacancies()` - Получает список всех вакансий с информацией о компании, названии, зарплате и ссылке.
   - `get_avg_salary()` - Получает среднюю зарплату по всем вакансиям.
   - `get_vacancies_with_higher_salary()` - Получает список вакансий с зарплатой выше средней.
   - `get_vacancies_with_keyword()` - Получает список вакансий, содержащих ключевое слово в названии.

5. Модуль `config.py` содержит функцию config(), которая возвращает словарь с параметрами подключения к базе данных. 
Сюда из переменного окружения нужно загрузить имя пользователя, пароль, хост и порт. 


### <a id="title3">3. Установка проекта</a>
1. Клонируйте репозиторий:
```
git clone https://github.com/kirill-medny/Database_Project.git
```

2. Установите зависимости:
```
poetry install
```

3. Запуск кода:
```
python -m main
```
