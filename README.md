Описание файлов и логика программы:

main.py:

Главный файл, точка входа в программу.
Создает экземпляры классов DBManager и HeadHunterAPI.
Определяет последовательность действий:
Создает базу данных и таблицы, если их нет.
Получает данные о компаниях: либо из API, либо из файла, если он существует. Если из API, то сохраняет в файл.
Сохраняет данные о компаниях и вакансиях в базу данных.
Предоставляет пользовательский интерфейс для выбора операций с данными.
Использует функции из utils.py для работы с файлами.
Использует конфигурацию из config.py.
src/db_manager.py:

Класс DBManager отвечает за управление базой данных PostgreSQL.
Содержит методы:
create_database(): Создает базу данных, если она не существует.
create_tables(): Создает таблицы employers и vacancies с необходимыми полями и связями.
save_companies_to_db(): Сохраняет данные о компаниях в таблицу employers.
save_vacancies_to_db(): Сохраняет данные о вакансиях в таблицу vacancies.
get_companies_and_vacancies_count(): Получает список компаний и количество их вакансий.
get_all_vacancies(): Получает список всех вакансий с информацией о компании, названии, зарплате и ссылке.
get_avg_salary(): Получает среднюю зарплату по всем вакансиям.
get_vacancies_with_higher_salary(): Получает список вакансий с зарплатой выше средней.
get_vacancies_with_keyword(): Получает список вакансий, содержащих ключевое слово в названии.
src/api_client.py:

Класс HeadHunterAPI отвечает за взаимодействие с API hh.ru.
Содержит методы:
get_company(): Получает информацию о компании по её ID.
get_vacancies(): Получает список вакансий компании по её ID.
src/utils.py:

Содержит функции для работы с файлами:
save_companies_to_file(): Сохраняет список компаний в файл в формате JSON.
load_companies_from_file(): Загружает список компаний из файла JSON.
config.py:

Содержит функцию config(), которая возвращает словарь с параметрами подключения к базе данных. Здесь хранятся (но НЕ в репозитории git, если он публичный!) имя пользователя, пароль, хост и порт. В реальном проекте эти параметры лучше брать из переменных окружения.
